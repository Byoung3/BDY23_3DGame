My game has parkour, maze, and object collecting sections. It was made so if you fall off the map, you respawn. 
To win you have to collect all 3 objects and reach the wooden platform after the maze.

I edited the player so that the jumping speed is faster in the "First Person Controller" script.
The previous delay between jumps made controlling the player feel unfair because it would not register jumps prior to the long delay.
